# Contributing

This is the original team's shared academic project. Changes should be reviewed and approved by **both** team contributors (see [CONTRIBUTORS.md](CONTRIBUTORS.md)). Use feature branches and pull requests rather than silently rewriting the history of the initial coursework.

Before suggesting a change, run the core smoke check (`scripts/check-engine.sh` or `.ps1`) and, when Maven is available, run tests under `backend/`. Do not commit local credentials, real database backups or identifying user data. For new endpoints, document request/response examples, error cases, and whether behavior is simulated.

The original 40-page coursework report is retained by the team outside this ready-to-publish repository, because the old document includes hardcoded demonstration credentials and descriptions that no longer match the updated schema. If the team wants a downloadable PDF, revise/redact the report first.
